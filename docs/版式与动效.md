# 版式与动效（免费版）

8 个版式，全部动作由代码按口播时点执行，Agent 只选版式、填字。所有“出现”都卡在这个词被说出的那一刻（`kb words` 生成的逐字时间）；没跑逐字对时，就按字幕条内字数估算。

## 通用动作（所有版式共用）

| 动作 | 效果 | 参数 |
|---|---|---|
| 换场 | 新画面从右侧滑入，旧画面最后一下左移淡出 | 滑入 0.22 秒、位移 80px；退场 0.1 秒、左移 35px |
| 人物窗形变 | 全屏 ↔ 左侧大方窗 ↔ 左下小圆窗之间平滑变形，主播始终在窗口正中 | 0.35 秒，换场前 0.14 秒开始 |
| 关键词短震 | 字淡入时左右轻晃一下再停稳 | 0.28 秒，横向 12px、纵向 4px、旋转 1.2° |
| 回弹 | 结论、标签弹出：先小、冲过头、回落、停稳 | 0.48 秒内缩放 0.65 → 1.17 → 0.94 → 1.06 → 1 |
| 擦出 | 箭头、标题条从左往右画出来 | 箭头 0.22 秒；标题条 0.32 秒，文字晚 0.14 秒淡入 |
| 逐字打出 | 第二级说明文字跟着口播一个个字打出 | 每秒 12 字 |
| 退焦 | 列表里说到下一项，上一项不再高亮 | 当前项变金色 |

## 8 个版式

**F0 纯人物** —— 人物全屏，只有底部字幕。可加 `tags`：左上角金色圆角小标签，说到时回弹弹出；说到下一个标签时前一个淡出，后一个字号大 1.7 倍。

**A1 金句关键词** —— 人物左侧大方窗，右侧上方白色引导句淡入上移，说到核心词时金色大字短震出现。核心词以「？」结尾时，说完后一个金色大问号像盖章一样砸下（0.12 秒从 1.6 倍落到 1，带 12° 旋转和画面轻震）。

**G2 章节编号卡** —— 人物大方窗。说到「第一 / 第二」时，大号金色编号和金底类别标签一起短震出现，标题在说到它时再出现。

**E1 并列关键词** —— 人物大方窗。3–5 个词按数量均匀铺开（3 个以内一行，4–5 个两行），每个词上方可配线条图标；说到哪个出现哪个，正在说的那个变金色。

**B1 左右对比** —— 人物缩成左下小圆窗。两栏以中线对称：先出左栏名称，中间金色箭头擦出后出右栏；各栏说明逐字打出；结论在胜出一栏下方回弹出现。

**B3 流程链** —— 段首先摆出暗色占位框，说到哪一环，那一环就点亮成米白卡片（0.25 秒从 0.85 倍放大到 1），前一环到这一环的箭头同时擦出；当前环变金色。`layout: vertical` 时人物在左侧大方窗，节点从上到下排，箭头向下。

**C1 数字卡** —— 人物小圆窗。段首先出暗色卡位，说到数字时金色大数字短震出现，卡框亮起，下方说明逐字打出。填了 `backdrop`（实物截图）时，截图铺满做压暗模糊底，数字卡变成半透明玻璃卡。

**D1 截图展示** —— 人物小圆窗，截图按原比例完整放进大画面区。填了 `focus` 时，说到 `focusSay` 那个词：镜头 0.45 秒推近到焦点区（让它约占画面 70%，最多 2.2 倍，不露出截图外的空白），随后金色框从左往右画出，框外压暗。
