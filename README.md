# 口播一键包装 · 免费版

**录完口播，剩下的交给 AI。**

你只管对着镜头把话说清楚。哪句该弹关键词、哪段该画流程图、数字什么时候砸出来，交给 AI 去想；字幕、对时、排版、动画、出片，交给代码去做。

一条命令，干巴巴的口播变成一条**有信息卡、有关键词动画、有节奏**的知识类短视频。

---

## 为什么做这个

做过口播的人都知道，包装比录制累得多：

- 剪映里一个个拉文字框，对着波形一帧帧找“这个词什么时候说的”；
- 关键词想放大强调，结果早出现半秒，剧透了；
- 好不容易排好版，发到抖音一看，右边的点赞、评论图标正好挡住重点；
- 一条 1 分钟的视频，包装两三个小时，第二天还得再来一遍。

这个工具把这些重复劳动全部交给机器。我（BOSS 畅老板）自己每天做 AI 知识类口播，完整版是我日常出片的主力工具；这里是把最核心、最常用的部分拿出来做的**免费版**，开箱就能出一条像样的片子。

## 它是怎么工作的

```
你的口播视频 + SRT 字幕
        │
        ▼
  AI 读字幕，想画面 ──►  plan.json（每段用什么版式、写什么字）
        │
        ▼
  代码做剩下的一切：
  逐字对时 → 排版 → 动画 → 避开平台遮挡 → 出片前检查 → 逐帧渲染 → 混回原声
        │
        ▼
     成片 MP4
```

**AI 只负责“想”，代码负责“做”。** 这是它和“让 AI 直接写一个动画网页”最大的区别：

- **不会手抖。** 坐标、字号、动作参数都写死在代码里，AI 改不了，所以不会今天画歪、明天出画。
- **字不会抢跑。** 每个关键词都去原声里找它被说出的那一刻（语音识别逐字对时），说到才出现，不剧透。
- **同一份计划，每次出片都一样。** 想改哪段，改 `plan.json` 里那一行就行，不用整条重来。
- **出片前自己先查一遍。** 字被抖音右侧图标挡住、压到人脸、跑出画面、小到手机上看不清……有问题直接报错，用中文告诉你改哪里。

## 免费版能做什么

### 8 个最常用的版式

| 版式 | 口播里出现… | 画面 |
|---|---|---|
| **F0 纯人物** | 感叹、过渡、开场 | 人物全屏，可在左上角弹出金色小标签点题 |
| **A1 金句关键词** | 一个结论、一个问题 | 人物退到左侧，核心词金色大字震出；问句会砸下一个大问号 |
| **G2 章节编号卡** | 第一、第二、方法一 | 大号编号 + 金底类别标签，一眼看出讲到第几部分 |
| **E1 并列关键词** | 3–5 个并列的东西 | 词语带图标均匀铺开，说到哪个亮哪个 |
| **B1 左右对比** | 原来…现在…、A 和 B | 两栏对称，箭头擦出，结论回弹落在胜出一边 |
| **B3 流程链** | 先…再…然后… | 占位框依次点亮，箭头一节节画出来，横排竖排都行 |
| **C1 数字卡** | 具体数字 | 金色大数字说到即出，下方说明逐字打出 |
| **D1 截图展示** | 讲到某个网站、仓库、软件 | 真实截图完整铺开，说到重点时镜头推近、金框圈出 |

每个版式具体怎么动、参数多少，见 [docs/版式与动效.md](docs/版式与动效.md)。

## 快速开始

需要：Node.js 20 以上、[FFmpeg](https://ffmpeg.org/download.html)（命令行能运行 `ffmpeg` 和 `ffprobe`）。

```bash
git clone https://github.com/boss-chang2026/koubo-oneclick-packaging-free.git
cd koubo-oneclick-packaging-free
npm install
npm run browser   # 下载无头浏览器（约 100MB）
npm run font      # 推荐：下载开源粗黑体 Noto Sans SC Black（约 9MB，可免费商用）
npm run demo      # 生成一段测试视频并出片，能出片就说明装好了
```

推荐再装上逐字对时，文字出现的时机会准很多（首次运行会自动下载约 500MB 的语音模型）：

```bash
pip install faster-whisper
```

## 怎么用

准备好两样东西：

1. **剪好的口播视频**：横屏，1920×1080 最佳，气口、废话已经剪掉；
2. **它的 SRT 字幕**：剪映、必剪等工具都能一键导出。

然后对 AI 说一句：

> 用口播一键包装免费版，包装这条视频：视频 `<路径>`，字幕 `<路径>`。

AI 会按 [SKILL.md](SKILL.md) 的步骤自己走完：建工程 → 逐字对时 → 写分镜 → 检查 → 出片，最后把成片路径交给你。不满意哪一段，直接跟它说“第 12 秒换成对比”“这几个字改短一点”，它改完重新出片。

喜欢自己动手，也可以照着 [examples/demo/plan.json](examples/demo/plan.json) 写计划，用命令行出片：

```bash
node bin/kb.mjs catalog              # 看 8 个版式怎么用、有哪些字段
node bin/kb.mjs words  plan.json     # 逐字对时
node bin/kb.mjs check  plan.json     # 出片前检查
node bin/kb.mjs render plan.json     # 出片 → .cache/out/preview.mp4（加 --proxy 先出快速预览）
```

## 常见问题

**需要显卡吗？** 不需要。渲染用的是无头浏览器逐帧截图；在 M 系列芯片的 Mac 上，22 秒的片子十几秒出完。

**没装 faster-whisper 能用吗？** 能。文字出现时点会按字幕条里的字数估算，大体对得上，但不如逐字对时准。

**能做竖屏吗？** 免费版只支持横屏口播（会自动避开抖音竖屏信息流里横屏视频右侧的图标列）。

**字体、配乐有版权问题吗？** 仓库不附带任何字体、音乐、Logo。推荐字体由你自己一键下载开源的 Noto Sans SC Black（SIL OFL，可免费商用），也可以换成你自己有授权的字体。
